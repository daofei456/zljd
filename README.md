# 强制执行官 - H5学习计时App

一个简洁高效的考研/考公学习计时工具，通过毒舌监督机制帮助你专注学习。

## 核心功能

### 1. 拟真自习室计时器
- 支持 25/45/60 分钟番茄钟
- 高颜值沉浸式自习室界面
- 切出 App 自动停止计时，记录"逃跑"

### 2. 人格化毒舌弹窗
- 魔鬼监督官人设
- 开始学习、中途放弃、完成任务时的不同语录
- 激励与压力并存的监督方式

### 3. 复习日报海报生成
- 一键生成精美学习报告长图
- 包含学习时长、完成科目、监督官评语
- 适合小红书分享

## 使用方法

1. 选择学习时长（25/45/60分钟）
2. 点击"入座学习"，选择科目
3. 开始专注学习，不要切出App
4. 完成后自动生成学习海报

## 技术栈

- 纯 HTML/CSS/JavaScript
- 无需任何依赖框架
- 响应式设计，支持移动端

## 开始使用

直接在浏览器中打开 `index.html` 即可使用。
